# ぽんぽこ もりの だいぼうけん — ゲーム設計書

最終更新: 2026-08-09  
対象: おおむね1歳6か月〜2歳6か月、主端末はiPad  
配信: GitHub Pagesで動く静的PWA

## 1. プロダクトの約束

このゲームは、問題文を理解して正解ボタンを選ぶ教材ではない。子どもが画面に触れ、動かし、その結果を見て自然に「見つける」「引く」「道を進む」という関係を学ぶ遊びである。

画面内の文字は保護者の補助情報に限り、遊びの成立には使わない。音声指示や読み上げも使わず、短いアクション音、同期した動き、色、位置で次の操作を伝える。

### 非言語UXの共通文法

1. 動かせるものだけが、ゆっくり呼吸するように動く。
2. 操作方向は、手のアニメーションと対象物の小さな予備動作を同時に見せる。
3. 操作中は対象が指に即時追従する。
4. 成功すると対象物がたぬきまたは目的地まで大きく移動する。
5. たぬきが同時にポーズを変え、子どもの操作と結果を結びつける。
6. 何もしない時間が続いた場合だけヒントを再表示する。正解を常時囲って答えを露出しない。

### 失敗の扱い

減点、制限時間、ゲームオーバー、赤い×、警告音は設けない。十分に操作できなかった場合は対象物が柔らかく元に戻り、もう一度だけ操作方向を実演する。

## 2. セッション構成

標準セッションは以下の3アクティビティ、各3ラウンドで構成する。

1. 果物: `くだもの かくれんぼ`
2. 野菜: `やさい すっぽん`
3. 動物: `どうぶつ おさんぽ`

保護者設定では1種類だけを繰り返すこともできる。1ラウンドはおおむね10〜25秒、標準セッションは約3〜5分を目安にする。

アクティビティの開始時は約1秒の無言デモを見せる。デモ画面にも長文は出さず、「対象物＋手の動き＋変化後」の関係を大きく表示する。

## 3. ゲーム1 — くだもの かくれんぼ

### ねらい

- 隠れた物を探す視覚探索
- 物が隠れても存在するという物の永続性
- 果物の形と色への親しみ
- こする動きと結果の因果関係

### 画面とたぬき

画面全体が果樹園になる。上段から中央に大きな葉の茂みを2〜3個配置し、果物が少しだけ見える。たぬきは中央下でかごを持つ。茂み、果物の移動軌道、かごが重ならないようにする。

### 操作

- 葉の茂みを左右にこすると葉が散り、隠れていた果物が徐々に見える。
- 1歳児向けの救済として、同じ茂みを2回タップしても発見できる。
- 一定量こすると葉が左右へ開き、果物が跳び出して弧を描き、たぬきのかごへ入る。
- こすっている間は葉と果物が指へ即時反応する。単なる回答ボタンにはしない。

### ラウンド

| ラウンド | 隠れている果物 | 個数 | 変化 |
| --- | --- | ---: | --- |
| 1 | りんご・みかん・ぶどう | 3 | 大きな茂み、短いこすり距離 |
| 2 | もも・さくらんぼ・レモン | 3 | 茂みが画面全体に広がる |
| 3 | いちご・スイカ・バナナ | 3 | 果物が少し上下に揺れ、探索範囲が広がる |

果物の種類を指定して選ばせない。すべて見つけることが目的であり、色の違いは探索の手がかりとして体験する。

### フィードバック

- こする: 葉のさざめき音、葉の回転、細かな葉粒子
- 発見: 軽いポン音、果物の跳ね、たぬきが手を伸ばす
- かごに入る: 木琴風の短い着地音、かごが弾む
- 全発見: たぬきがジャンプ、果樹園に花が咲く

## 4. ゲーム2 — やさい すっぽん

### ねらい

- 上方向へのドラッグと手指の運動計画
- 地上の葉と地下の野菜の関係
- 野菜の形、色、種類への親しみ
- 力をためて結果が起こる因果関係

### 画面とたぬき

画面中央から下を大きな畑にする。土から葉だけが見え、その下に野菜本体が埋まっている。たぬきは画面下の左寄りで応援し、収穫かご／荷車は右下に置く。ドラッグ対象と重ならない。

### 操作

- 葉をつかんで上へ引くと、野菜が指に比例して土から現れる。
- 必要距離まで引くと抵抗が抜け、野菜が「すっぽん」と飛び出す。
- 距離が足りない場合は土が柔らかく揺れ、野菜がゆっくり戻る。
- タップでも少しずつ持ち上がり、2回で収穫できる救済を用意する。
- 横方向のずれを厳密に判定しない。上方向の意図だけを評価する。

### ラウンド

| ラウンド | 野菜 | 個数 | 変化 |
| --- | --- | ---: | --- |
| 1 | 大根・キャベツ・かぼちゃ | 3 | 短い引き距離、太い葉 |
| 2 | にんじん・玉ねぎ・枝豆 | 3 | 畑の横幅を使用 |
| 3 | きゅうり・なす・さつまいも | 3 | 土の抵抗と飛び出し方に小さな個性 |

### フィードバック

- つかむ: 低いコト音、葉が握られるように縮む
- 引く: 土が割れ、野菜が連続的に見える
- 途中で離す: 土の柔らかなボフ音、怒らず元に戻る
- 収穫: 「すっぽん」に相当する短い上昇音、土粒子、野菜の一回転
- 荷車へ入る: たぬきが押すポーズ、荷車が弾む

## 5. ゲーム3 — どうぶつ ぽんぽこパレード

### ねらい

- 広い経路を追う目と手の協応
- 左から右、手前から目的地への空間的な連続性
- 動物の姿、模様、大きさへの親しみ
- 順番に進む予測と達成感

### 画面とたぬき

たぬきが画面左からパレードを先導し、右へ続く4個の大きな足あとを進む。各足あとの近くには葉や舞台幕に隠れた動物が1匹ずつ待っている。たぬきが到着すると動物が全身を見せ、画面下のパレード列へ加わる。各ラウンド4匹、3ラウンドで指定された12匹すべてが登場する。

### 操作

- たぬきをつかんで右方向へ動かすと、広い許容範囲の中で次の足あとへ吸い付く。
- 正確な線なぞりは要求しない。右方向への移動量を主に評価する。
- 次の足あとをタップしてもたぬきがそこまで進む救済を用意する。
- 足あとを1つ通るたび、待っていた動物が跳ねて登場し、たぬきの後ろへ並ぶ。
- 最後まで進むと4匹とたぬきが一緒に短いパレードをする。子どもに種類を選ばせる問題にはしない。

### ラウンド

| ラウンド | 登場する動物 | 舞台 | 経路の表現 |
| --- | --- | --- | --- |
| 1 | 犬・猫・ぶた・鳥 | 花の草原 | 芝生を弾む緩い弧 |
| 2 | ライオン・ぞう・キリン・しまうま | 金色の草原 | 大きさの違う足あと |
| 3 | パンダ・かば・さる・ラクダ | 世界の森 | 葉と小石がつながる道 |

### フィードバック

- つかむ: たぬきが小さく足踏みし、足あとが次の1個だけ光る
- 移動: 軽い足音、たぬきが指に追従しながら次の定位置へ進む
- 足あと到達: 葉が開き、対応する動物が全身で跳び出す
- 仲間入り: 動物が画面下の列へ移動し、たぬきと同じリズムで一度跳ねる
- 完了: たぬきが先頭で手を振り、4匹が左右へ揺れる短いパレード

## 6. たぬきの演出規則

たぬきは全ゲームの感情的な案内役である。

- 果物: 下中央、かごポーズ。果物が飛ぶ瞬間だけ手を伸ばす。
- 野菜: 下左、手を振る／押すポーズ。指を追わず定位置。
- 動物: たぬき自身が先導役として足あと間を段階的に移動する。pointer座標へ無制限に追従せず、経路の広い範囲へ制約する。
- ラウンド完了: その場でジャンプし、完了後は必ず次の定位置へ戻す。
- 画面外へ身体が切れない。少なくとも足先まで安全領域内に置く。
- 対象物、目的地、HUDの上には出さない。

## 7. 共通画面と進行

### ホーム

- 大きなたぬきと中央の開始ボタンを主役にする。
- 果物、野菜、動物の小さなモチーフが周囲で動き、内容を予告する。
- 保護者ボタンは右上、安全領域内に固定する。

### HUD

- 左: ホームへ戻る保護者向けボタン
- 中央: 3アクティビティ×3ラウンドの進行。現在テーマのアイコンを大きくする。
- 右: 保護者設定
- HUDは遊びの主要対象より弱いコントラストにする。

### 最終画面

果物と野菜のピクニック、パレードに加わった動物たち、中央で跳ぶたぬきを一つの場面に統合する。紙吹雪だけで終わらず、3ゲームの成果が同時に見えることを達成報酬にする。

## 8. 音

Web Audio APIで短い効果音のみ生成する。音声、読み上げ、BGM、動物の鳴き声は使用しない。

- 触る: 30〜80ms
- 連続操作: 低音量で間引く
- 収集／到達: 150〜350ms
- ラウンド成功: 500ms未満
- 最終成功: 1秒未満

同じ操作には同じ音色を割り当て、音だけでも因果関係が一貫するようにする。

## 9. アクセシビリティと安全性

- 主要タッチ対象は原則72px以上。
- Pointer Eventsを使用し、マウスでも検証可能にする。
- `touch-action`は必要なゲーム対象だけに設定する。
- `prefers-reduced-motion`と保護者設定を尊重する。
- モーション低減時も、位置変化を瞬間移動にせず短いフェードで因果を残す。
- 色だけに依存せず、輪郭、位置、動きも併用する。
- 端末外通信、広告、解析、個人情報収集を行わない。

## 10. 状態と保存

- 保存対象: アクション音、モーション低減、遊ぶテーマ、完了セッション数。
- ラウンド途中の状態は保存しない。中断後は安全にホームへ戻る。
- 既存バージョンの設定値は可能な範囲で新テーマ名へ移行する。

## 11. 完成条件

次のすべてを満たして初めてリリース可能とする。

- 3ゲームの主要操作が互いに異なる。
- 各ラウンドを文字と音声なしで完了できる。
- タップ救済だけでなく、本来の身体操作が十分に楽しい。
- 不十分な操作と誤操作から必ず回復できる。
- たぬきの全身がiPad縦横で自然な位置に見える。
- 全対象がHUD、たぬき、画面端と不自然に重ならない。
- 全9ラウンド、誤操作、保護者設定、完了、再挑戦を自動または半自動ブラウザ試験で確認する。
- `npm test`、`npm run lint`、`npm run build`、`git diff --check`が成功する。
- GitHub Pages公開URLで同じ通し試験が成功する。
