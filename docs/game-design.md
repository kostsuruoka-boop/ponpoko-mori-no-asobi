# ぽんぽこ もりの だいぼうけん — ゲーム設計書

- 最終更新: 2026-08-09
- 対象: おおむね1歳6か月〜3歳、主端末はiPad
- 配信: GitHub Pagesで動く静的PWA

## 1. プロダクトの約束

このゲームは、幼児が主役のたぬきと一緒に「物を動かした結果」を楽しみながら、語彙、分類、視覚照合、文字と音の関係へ触れる遊びである。問題文、制限時間、得点、失敗演出は使わない。

共通ルールは次のとおり。

1. 動かせる物は大きく、ゆっくり呼吸するように動く。
2. 最初の操作対象から目的地まで、手のアニメーションで実演する。
3. ドラッグ中は物が指に即時追従する。
4. 正しい場所に届くと、対象物、たぬき、効果音、必要な発音が同期する。
5. 集めた物は大きな完成盤へ残り、ラウンド終了後も消えない。
6. 完成盤は自動で切り替えない。子どもが大きな「つぎへ」を押すまで表示する。
7. 間違いは柔らかく元へ戻し、正しい場所を一度だけ実演する。
8. たぬきは常に全身が見え、成功ごとにポーズと感情マークで反応する。

## 2. モード選択とセッション

ホーム画面には主役のたぬきと4枚の大きなモードカードを常時表示する。保護者設定を開かなくても、子どもが絵から遊びを選べる。

| モード | ラウンド | 主な知育要素 | 主操作 |
| --- | ---: | --- | --- |
| ぽんぽこ農園 | 3 | 生育場所、食べ物の語彙、因果関係 | 収穫して棚へ運ぶ |
| どうぶつ広場 | 3 | 姿・輪郭の照合、動物語彙、一対一対応 | 動物を同じ影へ運ぶ |
| ひらがな おとの森 | 3 | 字形と日本語音の対応 | 音の文字をたぬきへ届ける |
| ABC おとの森 | 3 | 大文字・小文字・英語音の対応 | 音の文字をたぬきへ届ける |

各モードは単独の短いセッションである。1ラウンドを完成すると結果を好きなだけ見られ、明示的に次へ進む。3ラウンド後は、そのモードで集めた物を並べた専用エンディングを表示する。

## 3. ぽんぽこ農園

### ねらい

- 木、棚、低い株、つる、地面、土中という生育場所への親しみ
- 果物・野菜18種類の姿と日本語名の対応
- 物をつかむ、引く、運ぶという目と手の協応
- 6個が空の棚から満杯になる一対一対応と達成感

### 操作と結果

- 木・棚・株・つる・地上の作物は、元の場所から十分に動かすと収穫になる。
- 根菜は上方向へ引くと土から抜ける。きゅうりなど地上で育つ物に土中演出を使わない。
- 収穫物は弧を描いて画面下の6枠の棚へ入り、そのラウンドの終了まで大きく残る。
- 成功時に日本語名を一度発音し、たぬきが手を伸ばしてから跳ねる。
- 本来のドラッグが難しい場合のみ、同じ作物への2回タップを救済入力とする。

### 生育場所

| 生育場所 | 登場する物 |
| --- | --- |
| 木 | りんご、みかん、もも、さくらんぼ、レモン |
| 果樹・草丈の高い株 | バナナ |
| 棚 | ぶどう、きゅうり |
| 低い株 | いちご、枝豆、なす |
| つる | スイカ、かぼちゃ |
| 地上 | キャベツ |
| 土中 | 大根、にんじん、玉ねぎ、さつまいも |

### ラウンド

1. 果樹園: りんご、みかん、もも、大根、にんじん、キャベツ
2. 棚と株: ぶどう、さくらんぼ、いちご、枝豆、きゅうり、なす
3. 日なたの畑: レモン、バナナ、スイカ、かぼちゃ、玉ねぎ、さつまいも

## 4. どうぶつ広場

### ねらい

- 動物の全身と輪郭の視覚照合
- 4匹と4個の場所の一対一対応
- 動物12種類の日本語名への親しみ
- 好きな順番で考え、配置を完成させる主体性

### 操作と結果

- 上半分に4個の大きな動物の影、下半分に4匹のカラー動物を表示する。
- 動物は好きな順でつかみ、同じ影へドラッグする。順番ボタンは存在しない。
- 一致すると影がカラーの動物へ変わり、その場所でラウンド終了まで残る。
- 別の影へ置いた場合は動物が元へ戻り、正しい影が一度だけ呼吸する。
- 動物に触れた時と成功時に名前を発音する。
- 2回タップは正しい影へ移動する救済入力であり、主操作はドラッグである。
- 4匹が揃うと全員とたぬきが同時に跳ね、完成盤を維持する。

### ラウンド

1. 草原: 犬、猫、ぶた、鳥
2. サバンナ: ライオン、ぞう、キリン、しまうま
3. 世界の森: パンダ、かば、さる、ラクダ

## 5. ひらがな おとの森

### ねらい

- 一つの字形と一つの日本語音を結び付ける
- 近い文字の中から同じ字形を見つける
- 3文字を空の枠へ集める順序と達成感
- 発音を何度でも自分で再生する能動的な聴覚学習

### 操作と結果

1. 大きな見本カードに現在のひらがなを表示し、その音を発音する。
2. 3個の大きな音バブルを表示する。各バブルへ触れると、その文字自身を発音する。
3. 見本と同じ文字を、たぬき横の音の輪へドラッグする。
4. 正しい文字は下の3枠へ移動して残る。違う文字は音を鳴らして元へ戻る。
5. 見本の音ボタンで何度でも発音を再生できる。
6. 正しい文字への1回タップも救済入力として受け付ける。

### カリキュラム

現代仮名の基本46文字を五十音順で保持する。1ラウンド3文字、1セッション9文字を扱う。セッション完了後に開始位置を9文字進めて端末内へ保存し、繰り返し遊ぶと46文字すべてを巡回する。

対象文字: あいうえお、かきくけこ、さしすせそ、たちつてと、なにぬねの、はひふへほ、まみむめも、やゆよ、らりるれろ、わをん。

## 6. ABC おとの森

ひらがなと同じ身体文法を使い、学ぶ内容だけを英字へ変える。見本カードと音バブルは大文字と小文字を同じ面に表示し、英語音声で文字名を発音する。

- 対象はA〜Zの26文字。
- 1ラウンド3文字、1セッション9文字。
- 完了後に開始位置を9文字進め、端末内に保存する。
- Zの次はAへ戻るため、どの開始位置でも常に3文字を提示できる。
- 日本語音声を英字に流用せず、`en-US`音声を選択する。

## 7. たぬきの役割

たぬきは装飾ではなく、操作結果を感情へ変換する共同プレイヤーである。

- ホーム: 大きく手を振り、4モードを指し示す。
- 農園: 収穫棚の横でかごを持ち、つかむ時に手を伸ばし、棚へ入ると跳ねる。
- 動物: 動物置き場の横で見守り、正解時はハート、間違い時は穏やかな考える動きをする。
- 文字: 音の輪の隣でかごを持ち、正しい文字を受け取ると音符を出して跳ねる。
- ラウンド完了: 星を出してジャンプする。子どもが次へ進むまで完成物と一緒に残る。
- 端末回転時は左右の安全範囲へ位置を再計算し、身体を画面外へ出さない。

## 8. 音

### 効果音

Web Audio APIで生成し、耳障りな矩形波やゲーム内容と無関係な電子音を避ける。

- 葉・作物: 短いノイズと柔らかな上昇音
- 根菜: 低い土音と丸い抜け音
- 棚への着地: 短い木質音
- 動物照合: 2音の柔らかなチャイム
- 文字成功: 明るい2音
- 完成: 1秒未満の4音

### 音声

Speech Synthesis APIを使用し、遊び方の指示やナレーションには使わない。学習対象そのものだけを発音する。

- 農園・動物: 日本語名、`ja-JP`
- ひらがな: 文字の音、`ja-JP`
- ABC: 英字名、`en-US`
- 発音前にキューを取り消し、音声が重なって理解不能にならないようにする。
- 保護者設定で効果音と音声を別々に無効化できる。

## 9. 状態、安全性、アクセシビリティ

- タッチ対象は原則72 CSS px以上。
- Pointer Eventsを使い、1対象につき1つの`pointerId`だけを扱う。
- ドロップ領域には見た目より広い許容範囲を持たせる。
- `prefers-reduced-motion`と保護者設定を尊重する。
- 色だけに依存せず、輪郭、位置、動き、音を併用する。
- 広告、解析、外部トラッキング、個人情報収集を行わない。
- 保存対象は設定、モード別完了回数、文字カリキュラム位置だけである。

## 10. 複数周回の安定性

以前の実装では、画面を離れた後もWeb Animationの完了処理が生き、古いラウンドの処理が次のセッションへ割り込めた。現行実装は次を必須とする。

- 各画面・ラウンドに単調増加する`lifecycle`番号を持つ。
- タイマーは作成時の番号と現在番号が一致する場合だけ実行する。
- 画面離脱時に全タイマー、Web Animation、Pointer Event、音声、粒子を破棄する。
- ラウンドのPointer Eventは`AbortController`へまとめる。
- 再挑戦、途中帰宅、別モード開始、端末回転で古い処理を継続しない。

## 11. 完成条件

- 農園18種が適切な生育場所にあり、きゅうりを土中に置かない。
- 動物12種を順番ボタンなしで任意順に照合できる。
- ひらがな46文字と英字26文字が巡回可能で、発音言語が正しい。
- 全ラウンドで成果が完成盤に残り、自動遷移しない。
- たぬきが各成功へ明確に反応し、縦横画面で全身が収まる。
- 正規ドラッグ、救済入力、間違い、途中離脱、複数セッションから必ず回復する。
- `npm test`、`npm run lint`、`npm run build`、`git diff --check`が成功する。
- iPad相当の縦横画面とGitHub Pages公開URLで4モードを完走する。
