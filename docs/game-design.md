# ゲーム設計書（v6.3 正本）

要求の正本は [`product-requirements.md`](./product-requirements.md)。このファイルは**その要求をどう実現しているか**を定義する。
コードと食い違ったら、コードを設計に戻すか、設計を意図的に更新して理由を書く。

対象: **1歳10ヶ月**（2026-08時点）。読字・言語理解・精密操作は前提にしない。

---

## 1. 全モード共通の骨格

### 1.1 操作は「タップ」か「引っ張る」の2つだけ

- **選ぶ**もの（どうぶつの選択肢、文字表の升、つぎへ）＝**タップ**
- **収穫する**もの（畑の作物、畑の文字）＝**引っ張る**

引っ張る向きは現実に従う。**頭上のものは下へ（もぎ取る）、地面のものは上へ（引っこ抜く）。**
この「頭上か地面か」の宣言は `content.js` の `HABITAT_PULL` **1箇所だけ**にあり、
引っ張る向き・誘導の指の動き・盤面の列（奥／手前）がすべてそこから決まる。ズレようがない。
スプライトは正しい向きにしか動かないので、逆に引いても何も起きない。この「動かなさ」自体が教え方になっている。

ダブルタップ、長押し、斜めのスワイプ、ピンチ、精密なドロップ先指定は一切使わない。
引っ張りのしきい値は44pxと浅く、途中で離せばバネのように戻る。

**引っ張る向きは、作物ごとに矢印で常に出ている。**
木や棚の実の下には下向き、地面のものの上には上向きの矢印がゆっくり動く。
全部の作物に出るので**答えのヒントにはならず**、「どっちへ動かすか」だけを教える。
指を置いた瞬間に矢印は消える（もう作物自身が動いて見せているため）。

**同じものを3回タップしたら、引っ張れなくても収穫できる。**
幼児が詰まったまま進めなくなる事故を防ぐための逃げ道で、そこに至るまでに誘導は最終段階へ上がっている。

### 1.2 画面は3領域に固定

どのモードでも同じ場所に同じ役割がある。子どもは「どこを見て、どこを押すか」を一度覚えれば全モードで使える。

| 領域 | 役割 | 中身 |
| --- | --- | --- |
| **ask（お願い領域）** | 今なにを探すのか | たぬき＋吹き出し。吹き出し自体がボタンで、押すと質問をもう一度読み上げる |
| **play（あそび領域）** | 押す対象がすべてここにある | 畑／選択肢カード／文字表 |
| **collect（成果領域）** | できたものが残る | 見つけたものが順に埋まる。ラウンド完成まで消えない |

横向きは `ask | play` の2列＋下段に collect、縦向きは `ask / play / collect` の3段。

### 1.3 誘導は必ず「触るべきもの」を指し、必要な動きを真似る

無操作時間と誤タップ回数から段階を決める（`hintStage()` として純関数化、試験あり）。

| 段階 | 発火条件 | 見た目・音 |
| --- | --- | --- |
| 0 | 直後 | 何も出さない（引っ張る向きの矢印は§1.1のとおり常時出ている） |
| 1 | 3.5秒 または 誤タップ1回 | お願いをもう一度読み上げる |
| 2 | 7.0秒 または 誤タップ2回 | 正解に柔らかい光の輪 |
| 3 | 10.5秒 または 誤タップ3回 | 正解に強い脈動＋**指アイコンをその要素の上に置く** |

段階3の指は、実際に触るべき要素の座標に毎フレーム追従する。
さらに、**その要素が引っ張るものなら指も引っ張る動きをする**（向きは要素の `data-pull` から読む）。
指の動き＝必要な操作、が同じ1つの値から出ているので、**誘導と実操作が食い違う余地が構造的にない。**

### 1.4 まちがえても損をしない

誤タップは減点でも失敗でもない。押したものが**自分の名前を名乗る**。
「にんじん」を押してしまったら「にんじん」と聞こえる。誤答そのものが語彙学習になる。
そのあと段階が1つ上がるので、迷子にはならない。

### 1.5 音の設計

- 効果音: Web Audio でその場合成（収穫・引き抜き・正解・着地・やさしい否定）。BGMなし。
- 音声: `speechSynthesis`。**物の名前・文字の音そのものが学習内容**なので必ず読む。
- 読み上げは新しい発話が古い発話を打ち消す。そのためモードごとに「答えの名前を言い切ってから次の質問」になる間合いを定数化している（`STEP_PACING`）。
- ほめ言葉は3回に1回。毎回入れると語彙の読み上げを潰す。

### 1.6 6つのあそび

| あそび | 中心となる力 | 操作 |
| --- | --- | --- |
| のうえん | 語彙（聞いて探す）／どこで育つか | 引っ張る |
| どうぶつ | 形の弁別 | タップ |
| ひらがな | 文字の形と音／五十音表 | タップ |
| ABC | 大文字小文字／文字の音 | タップ |
| ひらがなばたけ | 文字と音（自由探索） | 引っ張る |
| ABCばたけ | 文字と音（自由探索） | 引っ張る |

### 1.7 毎回ちがう出題

同じ遊びを繰り返しても盤面と出題順が変わる。ただし**保証は崩さない**。

| モード | ランダムになるもの | 崩さない保証 |
| --- | --- | --- |
| のうえん | どの作物がどのラウンドに出るか、列の中のどこに植わるか、頼む順番 | 3ラウンドで18種すべてがちょうど1回ずつ。1つの盤面に生育地が4種類以上混ざり、**奥の列に2〜3個、手前の列に3〜4個**に分かれる |
| どうぶつ | どの動物が同じラウンドに入るか、影の順番、選択肢の並び | 3ラウンドで12種すべて。選択肢は2→3→4と増える。おとりは同じラウンドの動物から出す |
| ひらがな・ABC | 出題順（表全体をシャッフルした並びを進む） | 1セッション15文字が全部ちがう。表を1周し終えるまで同じ文字は来ない |
| ひらがな・ABCばたけ | 出す文字と、どこに生えるか | 1セッション18文字が全部ちがう。**奥の列3つは木や棚、手前の列3つは地面**に生える |

農園は単純なシャッフルにしていない。素直に配ると「木の実ばかり6個」の盤面が出てしまうため、
作物は**その生育地がいちばん少ないラウンド**へ配る。同点はランダムに割る。

文字の並びは端末ごとに保存した種（シード）から作る。だから途中でアプリを閉じても続きが崩れず、
表を1周し終えたときだけ並びを作り直す。

### 1.8 たぬき

主役。ask領域で必ず質問者として登場し、正解で跳ね、まちがいで首をかしげ、完成で大喜びする。
ポインタを追いかけない。対象を隠さない。モードごとに姿勢が変わる（農園＝かご、どうぶつ＝手を伸ばす、文字＝手を振る）。

## 2. のうえん（語彙・生育場所）

**知育目標**: 果物・野菜の名前を音で聞いて絵と結びつける（受容語彙・指差し）。あわせて「どこで育つか」を体で覚える。

- 盤面は3×2の6区画。各区画に**生育地のSVG**が描かれ、作物はその中の正しい位置にいる。
- **もぎ取るもの（木・棚・バナナ）は奥の列、引っこ抜く・地面のものは手前の列。**
  畑を見たときの現実の奥行きに合う。どの作物がどの区画に来るかは毎回変わる（§1.7）。
- たぬきが1つの作物を絵と音で頼む（「りんご」）。畑からそれを探して**引っ張る**。
- 木・棚・バナナの木のものは**下へ**、土・茂み・つる・地面のものは**上へ**。
- 正解: 引いた向きに外れて → かご（collect）に残る → 名前を読み上げる。
- 6個ごとに1ラウンド、3ラウンドで**果物9種・野菜9種すべて**が登場する。

### 生育地（`src/scenery.js`）

背面レイヤーと前面レイヤーに分かれる。前面レイヤーが作物の下部を隠すことで「埋まっている」が成立する。

| 生育地 | 作物 | 見た目と収穫 |
| --- | --- | --- |
| `tree` | りんご・みかん・もも・さくらんぼ・レモン | 幹と樹冠。実は樹冠の中にぶら下がる |
| `palm` | バナナ | 曲がった幹と大きな葉 |
| `trellis` | ぶどう・きゅうり | 棚から吊り下がる。きゅうりは縦向きに回転 |
| `bush` | いちご・えだまめ・なす | 茂みに埋もれ、手前の葉が下部に重なる |
| `vine` | すいか・かぼちゃ | 地面のつるの上に鎮座 |
| `ground` | キャベツ | 土の上に据わる |
| `soil` | だいこん・にんじん・たまねぎ・さつまいも | **土の畝が前面に来て下3割を隠す**。押すと土から持ち上がってから飛ぶ |

だいこんとにんじんは素材が斜めなので、植わって見えるよう回転させている（`PRODUCE_ROTATION`）。

## 3. どうぶつ（形の弁別）

**知育目標**: シルエット（輪郭）だけで対象を同定する。あわせて動物名と鳴き声。

- 吹き出しの中に**黒い影が1つ**。play領域に**選択肢カードが複数**。影に合う動物を押す。
- 正解: カードが影へ飛び、影が色付きの動物に変わって踊る。名前＋鳴き声（「いぬ。ワンワン」）。
- 難易度は選択肢の数だけで上がる。**ラウンド1は2択、2は3択、3は4択**。
- 3ラウンドで12種すべてが出る。どの動物が同じラウンドに入るかは毎回変わる。

鳴き声は擬音が定着している動物（いぬ・ねこ・ぶた・とり・ライオン・ぞう・さる）だけに付けている。無理に作らない。

---

## 4. ひらがな（文字の探索）

**知育目標**: 文字の形と音の結びつけ。あわせて五十音表という「地図」に触れる。

- play領域に**五十音図が常にすべて並ぶ**（10行×5段、横向き）。縦向きは5列×10行に転置する。
- ん は伝統的な図と同じく、わ行の い段に置く。や行・わ行の空白もそのまま残す。
- 吹き出しに探す文字が大きく出て、音が鳴る。表から同じ文字を押す。
- 正解: その升が金色に染まって**セッション中ずっと残る**。さらに、その文字で始まる言葉がわかる場合はごほうびカードを出す（り→りんご、ね→ねこ など、農園とどうぶつで出会った絵を再利用）。
- 誤タップ: 押した文字が自分の音を鳴らす。**表のどこを押しても文字が読める**ので、自由に触ること自体が知育になる。
- 1ラウンド5文字、1セッション15文字。**出題順はランダム**で、次に遊ぶときは続きから（`curriculum` と並びの種を保存）。

---

## 4.5 ひらがなばたけ／ABCばたけ（文字の収穫）

**知育目標**: 文字の形と音。加えて「自分で選んで、自分で取る」経験。

- 畑に**文字の実が6つ**散らばっている。半分は木や棚に実り、半分は土に埋まっている。
- **どれを取るかの指示はない。** 好きなものを好きな順に引っ張る。
- 取ると音が鳴り、たぬきが跳ね、かごに残る。その文字で始まる言葉があれば絵と一緒に読み上げる。
- 間違いという概念がない。タップしただけでも文字の音は鳴る。
- 1ラウンド6文字、1セッション18文字。表を1周する進行は探すモードとは**別に**持つ。

吹き出しには「あと何個か」だけが出る。読めない子にも残りが数として見える。

---

## 5. ABC（文字の探索）

構造はひらがなと同じ。盤面は A〜Z。各升は大文字と小文字を**併記**する（`Aa`）ので、対応関係が自然に目に入る。
ごほうびカードは A→Apple のように単語と絵。**A〜Z の26文字すべてに絵がある**
（14文字は果物・動物の既存素材、12文字は `abc-sprites-v1.png` から）。

---

## 6. 進行と完成

- 1モード＝3ラウンド。ラウンド完成で盤面はそのまま残り、大きな「つぎへ」ボタンだけが出る。**自動で消えない。**
- 3ラウンド終わるとフィニッシュ画面。集めたものが並んで踊る。
- 制限時間・減点・ゲームオーバーは存在しない。

## 7. 保存

`localStorage` のみ（端末内）。設定、完了回数、文字カリキュラム位置と並びの種。
読み書きは try/catch で包む。ストレージが使えない端末でも遊べることを優先する。

## 8. 保護者メニュー

算数ゲート（2+3）の先に、効果音／音声／動きひかえめ の3設定、完了回数、記録リセット、
そして**再インストール**ボタン（キャッシュとService Workerを消して読み直す）を置く。
