# ゲーム設計書（v6 正本）

要求の正本は [`product-requirements.md`](./product-requirements.md)。このファイルは**その要求をどう実現しているか**を定義する。
コードと食い違ったら、コードを設計に戻すか、設計を意図的に更新して理由を書く。

対象: **1歳10ヶ月**（2026-08時点）。読字・言語理解・精密操作は前提にしない。

---

## 1. 全モード共通の骨格

### 1.1 操作は「タップだけ」

ドラッグ、ダブルタップ、長押し、スワイプ、ピンチは一切使わない。
幼児のiPad操作でドラッグは成功率が低く、「誘導どおりにやっても進まない」という v5 最大の欠陥の原因だった。

### 1.2 画面は3領域に固定

どのモードでも同じ場所に同じ役割がある。子どもは「どこを見て、どこを押すか」を一度覚えれば全モードで使える。

| 領域 | 役割 | 中身 |
| --- | --- | --- |
| **ask（お願い領域）** | 今なにを探すのか | たぬき＋吹き出し。吹き出し自体がボタンで、押すと質問をもう一度読み上げる |
| **play（あそび領域）** | 押す対象がすべてここにある | 畑／選択肢カード／文字表 |
| **collect（成果領域）** | できたものが残る | 見つけたものが順に埋まる。ラウンド完成まで消えない |

横向きは `ask | play` の2列＋下段に collect、縦向きは `ask / play / collect` の3段。

### 1.3 誘導は必ず「押すべきもの」を指す

無操作時間と誤タップ回数から段階を決める（`hintStage()` として純関数化、試験あり）。

| 段階 | 発火条件 | 見た目・音 |
| --- | --- | --- |
| 0 | 直後 | 何も出さない |
| 1 | 3.5秒 または 誤タップ1回 | お願いをもう一度読み上げる |
| 2 | 7.0秒 または 誤タップ2回 | 正解に柔らかい光の輪 |
| 3 | 10.5秒 または 誤タップ3回 | 正解に強い脈動＋**指アイコンをその要素の上に置く** |

段階3で表示される指は、実際に押すべき要素の座標に毎フレーム追従する。**誘導と実操作が食い違う余地が構造的にない。**

### 1.4 まちがえても損をしない

誤タップは減点でも失敗でもない。押したものが**自分の名前を名乗る**。
「にんじん」を押してしまったら「にんじん」と聞こえる。誤答そのものが語彙学習になる。
そのあと段階が1つ上がるので、迷子にはならない。

### 1.5 音の設計

- 効果音: Web Audio でその場合成（収穫・引き抜き・正解・着地・やさしい否定）。BGMなし。
- 音声: `speechSynthesis`。**物の名前・文字の音そのものが学習内容**なので必ず読む。
- 読み上げは新しい発話が古い発話を打ち消す。そのためモードごとに「答えの名前を言い切ってから次の質問」になる間合いを定数化している（`STEP_PACING`）。
- ほめ言葉は3回に1回。毎回入れると語彙の読み上げを潰す。

### 1.6 たぬき

主役。ask領域で必ず質問者として登場し、正解で跳ね、まちがいで首をかしげ、完成で大喜びする。
ポインタを追いかけない。対象を隠さない。モードごとに姿勢が変わる（農園＝かご、どうぶつ＝手を伸ばす、文字＝手を振る）。

## 2. のうえん（語彙・生育場所）

**知育目標**: 果物・野菜の名前を音で聞いて絵と結びつける（受容語彙・指差し）。あわせて「どこで育つか」を体で覚える。

- 盤面は3×2の6区画。各区画に**生育地のSVG**が描かれ、作物はその中の正しい位置にいる。
- たぬきが1つの作物を絵と音で頼む（「りんご、どーこだ」）。畑からそれを探して押す。
- 正解: 収穫アニメーション → かご（collect）に残る → 名前を読み上げる。
- 6個ごとに1ラウンド、3ラウンドで**果物9種・野菜9種すべて**が登場する。

### 生育地（`src/scenery.js`）

背面レイヤーと前面レイヤーに分かれる。前面レイヤーが作物の下部を隠すことで「埋まっている」が成立する。

| 生育地 | 作物 | 見た目と収穫 |
| --- | --- | --- |
| `tree` | りんご・みかん・もも・さくらんぼ・レモン | 幹と樹冠。実は樹冠の中にぶら下がる |
| `palm` | バナナ | 曲がった幹と大きな葉 |
| `trellis` | ぶどう・きゅうり | 棚から吊り下がる。きゅうりは縦向きに回転 |
| `bush` | いちご・えだまめ・なす | 茂みに埋もれ、手前の葉が下部に重なる |
| `vine` | すいか・かぼちゃ | 地面のつるの上に鎮座 |
| `ground` | キャベツ | 土の上に据わる |
| `soil` | だいこん・にんじん・たまねぎ・さつまいも | **土の畝が前面に来て下3割を隠す**。押すと土から持ち上がってから飛ぶ |

だいこんとにんじんは素材が斜めなので、植わって見えるよう回転させている（`PRODUCE_ROTATION`）。

## 3. どうぶつ（形の弁別）

**知育目標**: シルエット（輪郭）だけで対象を同定する。あわせて動物名と鳴き声。

- 吹き出しの中に**黒い影が1つ**。play領域に**選択肢カードが複数**。影に合う動物を押す。
- 正解: カードが影へ飛び、影が色付きの動物に変わって踊る。名前＋鳴き声（「いぬ。ワンワン」）。
- 難易度は選択肢の数だけで上がる。**ラウンド1は2択、2は3択、3は4択**。
- 3ラウンドで12種すべてが出る。

鳴き声は擬音が定着している動物（いぬ・ねこ・ぶた・とり・ライオン・ぞう・さる）だけに付けている。無理に作らない。

## 4. ひらがな（文字の探索）

**知育目標**: 文字の形と音の結びつけ。あわせて五十音表という「地図」に触れる。

- play領域に**五十音図が常にすべて並ぶ**（10行×5段、横向き）。縦向きは5列×10行に転置する。
- ん は伝統的な図と同じく、わ行の い段に置く。や行・わ行の空白もそのまま残す。
- 吹き出しに探す文字が大きく出て、音が鳴る。表から同じ文字を押す。
- 正解: その升が金色に染まって**セッション中ずっと残る**。さらに、その文字で始まる言葉がわかる場合はごほうびカードを出す（り→りんご、ね→ねこ など、農園とどうぶつで出会った絵を再利用）。
- 誤タップ: 押した文字が自分の音を鳴らす。**表のどこを押しても文字が読める**ので、自由に触ること自体が知育になる。
- 1ラウンド5文字、1セッション15文字。次に遊ぶときは続きから（`curriculum` に保存）。

## 5. ABC（文字の探索）

構造はひらがなと同じ。盤面は A〜Z。各升は大文字と小文字を**併記**する（`Aa`）ので、対応関係が自然に目に入る。
ごほうびカードは A→Apple のように単語と絵。既存素材で15文字ぶんの絵があり、
残りは追加素材（`assets/sprites/abc-*.png`）が入り次第、ビルドが自動で有効化する。

## 6. 進行と完成

- 1モード＝3ラウンド。ラウンド完成で盤面はそのまま残り、大きな「つぎへ」ボタンだけが出る。**自動で消えない。**
- 3ラウンド終わるとフィニッシュ画面。集めたものが並んで踊る。
- 制限時間・減点・ゲームオーバーは存在しない。

## 7. 保存

`localStorage` のみ（端末内）。設定、完了回数、文字カリキュラム位置。
読み書きは try/catch で包む。ストレージが使えない端末でも遊べることを優先する。

## 8. 保護者メニュー

算数ゲート（2+3）の先に、効果音／音声／動きひかえめ の3設定、完了回数、記録リセット、
そして**再インストール**ボタン（キャッシュとService Workerを消して読み直す）を置く。
