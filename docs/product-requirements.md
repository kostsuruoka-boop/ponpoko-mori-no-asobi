## 1. 誰のための、何か

| 項目 | 内容 |
| --- | --- |
| 対象ユーザー | 施主の娘（**1歳10ヶ月**、2026-09時点） |
| 目的 | **娘の喜ぶ顔が見たい。** 知育は主目的ではなく、遊びの副産物でよい |

| ホスティング | GitHub Pages（静的HTMLのみ。サーバー・DB・課金なし） |

「中学生の実装レベル」で止まっているものは未完成とみなす。

## 1.5 2026-09-05 の全面アップデート要求（最新・上位）

施主の言葉:

> この娘のためのアプリを全面アップデートしてほしい。
> 娘はたぬきが好きだ。とにかく、たぬきとそのほかの要素で楽しめればいい。
> 知育要素に振りすぎなくていい。どう言ったコンテンツがいいかはあなたに任せる。
> 1歳10ヶ月の娘でも操作できる素晴らしいUXを実現して。

ここから読み取った方針。**§2以降と衝突したら、この節が優先する。**

1. **楽しさが第一。知育は二番目。** 「知育要素が実在する」（§2-5）は引き続き満たすが、
   アプリの重心は**たぬきと遊ぶこと**に置く。知育モードを減らしはしないが、主役ではなくする。
2. **たぬきが遊びの対象そのものになる。** 質問する司会者ではなく、**触れるおもちゃ**にする。
   どの画面でも、たぬきを押せば必ず反応する。
3. **正解のない遊びを用意する。** 出題・正誤・答え合わせのない遊びを新設する。
   押せば必ず何かが起きる、という一点だけで成立させる。
4. **コンテンツの選定は受託側の裁量。** 施主は内容を指定していない。
5. **1歳10ヶ月が自力で操作できるUXであること。** ここは§2-2の再確認であり、緩和ではない。

実装した答え: **「たぬきと あそぶ」4種**（おんがくたい／いないいないばあ／ごはん／しゃぼんだま）を新設し、
ホームを「たぬきと あそぶ」→「みつけて あそぶ」の二段構成にした。詳細は
[`game-design.md` §1.8](./game-design.md) を参照。

## 2. 絶対要件

1. **iPadのホーム画面アイコンから起動して、確実に動く。** ここが壊れていたら他の全てに意味がない。
2. **1歳10ヶ月が自力で操作できる。** 文字が読めない、説明が理解できない前提で設計する。
3. **画面に出る誘導と、実際に必要な操作が完全に一致する。** ズレは「バグ」として扱う。
4. **見た目が破綻していない。** 特に農園の樹木・作物の配置は、現実の育ち方と矛盾しないこと。
5. **「みつけて あそぶ」6種には知育要素が実在する。** そこでは「触ると反応する」だけの遊びを知育と呼ばない。
   一方、**「たぬきと あそぶ」4種にこの要件は課さない**（§1.5-1）。あちらは楽しさだけで成立してよい。
6. **たぬきが遊びに参加している。** 単なる壁紙にしない。さらに§1.5-2により、
   **たぬき自身が押せる**こと。

## 3. 施主が明示的に却下した設計（2026-08-09 レビュー）

| 却下されたもの | 理由 | 対応方針 |
| --- | --- | --- |
| iPadホーム画面起動で無反応 | 画面は出るがタップが全部効かない | JSの起動失敗。互換性を落として単一クラシックスクリプト化し、起動監視と自己復旧を入れる |
| 農園モードの樹木・作物表示 | 全体的に間違っていて、おかしい | CSS図形をやめ、育ち方を再現したSVG生育地に置き換える |
| 農園・ひらがな・英語の操作誘導 | 表示される誘導と実操作が違い、理解を妨げる | 操作を**全画面タップのみ**に統一し、誘導は必ず「押すべき対象」を指す |
| 動物モードのゲーム内容 | 「今のは全然ダメ」 | **空のシルエット1つ＋複数の選択肢**から、合う動物を選ぶ形式へ全面変更 |
| ひらがな・ABCモードの知育性 | 「何も知育要素がない」 | **五十音表・アルファベット表を全部並べた盤面**の上で探す遊びへ全面変更 |
| ドラッグ主体の操作 | 幼児のiPad操作として成立していない | タップに統一（施主承認済み） |

## 4. 施主が与えた裁量

- **ゲーム性はゼロから見直してよい。**
- **収録する野菜・果物・動物は増やしてよい。**
- このフォルダとGitHubリポジトリに対して**何をやっても構わない**。ただし**整理された状態を保つこと**。
- 画像素材が必要なら**自分で調達する**。難しい場合のみ施主に直接依頼してよい。

## 5. やらないこと（施主要求から導かれる禁止事項）

- 減点・制限時間・ゲームオーバー・失敗状態
- 読解や音声指示の理解を必要とする誘導
- BGM、広告、アナリティクス、外部トラッキング、外部CDN依存
- 課金導線、外部リンク、SNS共有
- 精密なドラッグ、ダブルタップ、長押し、ピンチなどの複合操作

## 6. 完了の定義

以下がすべて満たされて初めて「できた」と言ってよい。

1. iPadのホーム画面アイコンから起動し、全モードを最後まで遊べる。
2. 縦向き・横向きの両方で、要素の重なり・見切れ・安全領域の食い込みがない。
3. 誘導表示が指す対象を押せば、必ず先へ進む。
4. 「みつけて あそぶ」の各モードに、言語化できる知育目標がある。
   「たぬきと あそぶ」の各モードに、言語化できる**楽しさの仕掛け**がある。
5. `npm test` / `npm run lint` / `npm run build` が通る。
6. 公開URLで実機確認済みである。
