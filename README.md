# ぽんぽこ もりの だいぼうけん

1〜2歳ごろの子どもが、動くたぬきと一緒に森を進むiPad向け知育Webゲームです。文字や音声指示に頼らず、対象物・空の枠・たぬきの反応を見れば次の操作が分かるよう設計しています。

## ゲーム体験

スタート後は3つの遊びがひと続きの冒険として進みます。

- **いろを集める**: かごと同じ色の木の実だけを3個集める。色の識別と分類を体験します。
- **かたちを運ぶ**: 同じ輪郭の穴へ丸・三角・四角をタップまたはドラッグする。形の照合と手指操作を体験します。
- **どんぐりを数える**: 1〜3個の空枠へどんぐりを1個ずつ入れる。数量と一対一対応を体験します。

たぬきは操作に合わせて画面内を走り、手を伸ばし、形を押し、成功すると跳び上がります。3つの遊びを終えると木が育つ全画面の達成演出が始まります。

## 1歳児向けの方針

- 遊び場をほぼ全画面にし、対象物を大きく配置
- 最初の操作だけ、指のアニメーションでタップ・ドラッグを提示
- 読み上げ音声なし。タップ、移動、収集、成功のアクション音だけ
- 不正解でも減点や警告音はなく、対象物とかごが優しく反応
- 形はドラッグに加えてタップでも自動的に運べる
- 1回は約3〜5分。保護者設定から1種類だけに絞ることも可能

設定と冒険回数は端末内だけに保存され、外部へ送信されません。

## ローカルで動かす

Node.js 20以上とPython 3を使用します。アプリ本体に外部パッケージはありません。

```bash
npm test
npm run lint
npm run build
npm run dev
```

`http://localhost:4173` をSafariまたはChromeで開いてください。

## GitHub Pages

`main`ブランチへのpushで、GitHub Actionsがテストとビルドを実行し、`dist/`をGitHub Pagesへ公開します。iPadではSafariの共有メニューから「ホーム画面に追加」を選ぶと、全画面に近い状態で利用できます。一度読み込んだ主要ファイルはオフラインでも使用できます。

## 構成

```text
src/                 アプリ本体
tests/               ゲームロジックの自動テスト
assets/              たぬきスプライト素材
public/              PWAマニフェスト、アイコン、Service Worker
scripts/             静的ビルド
.github/workflows/   GitHub Pages自動公開
```

## 画像素材

`assets/tanuki-sprites-v2.png`は、このゲーム専用にOpenAIの組み込み画像生成機能で作成し、クロマキー背景を除去したオリジナルの6ポーズスプライトです。

生成プロンプトの要旨: 「同じたぬきの3列×2行スプライト。手を振る、走る、手を伸ばす、かごを持つ、押す、跳ぶ。1〜2歳向けの丸く明るい絵本調。黄色い葉の首飾りを全ポーズで統一。文字・影・余分な物なし。単色マゼンタ背景」。
