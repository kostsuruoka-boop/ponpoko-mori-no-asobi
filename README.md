# ぽんぽこ もりの だいぼうけん

主役のたぬきと一緒に、農園・動物・ひらがな・ABCで遊ぶiPad向けの静的Webゲームです。おおむね1歳6か月〜3歳を対象に、大きな身体操作、成果が残る完成盤、物と文字の発音を組み合わせています。

公開版: https://kostsuruoka-boop.github.io/ponpoko-mori-no-asobi/

## 4つのゲーム

- **ぽんぽこ農園**: 自然な生育場所から果物・野菜を収穫し、6枠の棚へ運びます。3ラウンドで指定された果物9種・野菜9種がすべて登場し、成功時に名前を発音します。
- **どうぶつ広場**: 4匹を好きな順番で同じ輪郭へ運びます。完成した動物はその場に残って踊り、3ラウンドで指定された12種類が登場します。
- **ひらがな おとの森**: 見本の音を聞き、同じひらがなをたぬきへ届けます。基本46文字を1セッション9文字ずつ巡回します。
- **ABC おとの森**: 大文字・小文字と英語音声を結び付けます。A〜Zを1セッション9文字ずつ巡回します。

どのゲームもドラッグが主操作です。操作が難しい場合はタップによる救済があります。減点、制限時間、ゲームオーバー、BGM、広告、解析、外部トラッキングはありません。ラウンド完成後は結果を自動で消さず、子どもが大きな次ボタンを押すまで表示します。

## 収録内容

- 果物: りんご、みかん、ぶどう、もも、さくらんぼ、レモン、いちご、スイカ、バナナ
- 野菜: 大根、キャベツ、かぼちゃ、にんじん、玉ねぎ、枝豆、きゅうり、なす、さつまいも
- 動物: 犬、猫、パンダ、ライオン、ぞう、キリン、かば、さる、しまうま、ラクダ、ぶた、鳥
- 文字: 基本ひらがな46文字、英字A〜Z

たぬきは動物一覧には含めず、ホームと全ゲームで反応する独立したメインキャラクターです。

## ローカルで動かす

Node.js 20以上とPython 3を使用します。アプリ本体に外部ランタイム依存はありません。

```bash
npm test
npm run lint
npm run build
npm run dev
```

`http://localhost:4173`をSafariまたはChromeで開きます。`dist/`は生成物なので直接編集しません。

## GitHub Pages

`main`へのpushでGitHub Actionsが試験とビルドを行い、`dist/`をGitHub Pagesへ公開します。主要ファイルはService Workerへキャッシュされ、一度読み込んだ後はオフラインでも起動できます。

iPadではSafariの共有メニューから「ホーム画面に追加」を選ぶと、独立したアプリに近い表示で遊べます。縦向き・横向きの両方に対応しています。

## 構成

```text
src/                    アプリ本体、ゲームルール、音、スタイル
tests/                  DOMに依存しないゲームルール試験
assets/                 たぬき、果物、野菜、動物の画像スプライト
public/                 PWAマニフェスト、アイコン、Service Worker
scripts/                静的ビルド
docs/                   ゲーム設計、実装引き継ぎ、素材生成記録
.github/workflows/      GitHub Pages自動公開
```

設定、完了回数、文字カリキュラム位置は端末の`localStorage`だけに保存します。
