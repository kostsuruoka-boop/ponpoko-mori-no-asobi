# ぽんぽこ もりの だいぼうけん

1〜2歳ごろの子どもが、メインキャラクターのたぬきと一緒に果物・野菜・動物で遊ぶ、iPad向けの静的Webゲームです。文字や読み上げを理解しなくても、対象物と手の動き、たぬきの反応だけで遊べるよう設計しています。

公開版: https://kostsuruoka-boop.github.io/ponpoko-mori-no-asobi/

## 3つのゲーム

- **くだもの かくれんぼ**: 葉を左右にこすり、隠れた果物を見つけます。視覚探索、物の永続性、動きと結果の因果関係を体験します。りんご、みかん、ぶどう、もも、さくらんぼ、レモン、いちご、スイカ、バナナが登場します。
- **やさい すっぽん**: 土から見える野菜を上へ引き、収穫して荷車へ入れます。上方向の運動、地上と地下の関係、力をためる感覚を体験します。大根、キャベツ、かぼちゃ、にんじん、玉ねぎ、枝豆、きゅうり、なす、さつまいもが登場します。
- **どうぶつ ぽんぽこパレード**: 主役のたぬきを右へ導き、各地点の動物を仲間にします。経路追従、順番、動物の姿や模様への親しみを体験します。犬、猫、パンダ、ライオン、ぞう、キリン、かば、さる、しまうま、ラクダ、ぶた、鳥が登場します。

3ゲームは「正しい答えを選ぶ」同型の問題ではなく、こする・引く・道を進むという異なる身体操作です。本来のジェスチャーが難しい場合はタップでも進められます。失敗、減点、制限時間、ゲームオーバー、読み上げ音声、BGMはありません。音は短いアクション効果音のみです。

## ローカルで動かす

Node.js 20以上とPython 3を使用します。アプリ本体に外部ランタイム依存はありません。

```bash
npm test
npm run lint
npm run build
npm run dev
```

`http://localhost:4173`をSafariまたはChromeで開きます。`dist/`は生成物なので直接編集しません。

## GitHub Pages

`main`ブランチへのpushでGitHub Actionsがテストとビルドを行い、`dist/`をGitHub Pagesへ公開します。主要ファイルはService Workerでキャッシュされ、一度読み込んだ後はオフラインでも起動できます。

iPadではSafariの共有メニューから「ホーム画面に追加」を選ぶと、独立したアプリに近い表示で遊べます。縦向き・横向きの両方に対応しています。

## 構成

```text
src/                    アプリ本体、ゲームロジック、スタイル
tests/                  DOMに依存しないゲームルール試験
assets/                 たぬき、果物、野菜、動物の画像スプライト
public/                 PWAマニフェスト、アイコン、Service Worker
scripts/                静的ビルド
docs/                   ゲーム設計、実装引き継ぎ、素材生成記録
.github/workflows/      GitHub Pages自動公開
```

設定と完了回数は端末の`localStorage`だけに保存されます。広告、解析、トラッキング、個人情報の外部送信はありません。
